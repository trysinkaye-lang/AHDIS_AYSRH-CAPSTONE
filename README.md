# Adolescent Health and Development Information System (AHDIS)

AHDIS is an offline information system developed to support
adolescent health data encoding, profiling, monitoring,
reporting, and data management.

## Main Features

- Adolescent profiling and record management
- Dashboard and statistical summaries
- Adolescent age coverage: 9–19 years old
- Age brackets: 9–14, 15–17, and 18–19
- Health-related information and monitoring
- Reports and graphical visualizations
- Excel import and export
- User authentication and access control

## Technology

- PHP
- HTML, CSS, and JavaScript
- PHP Desktop (Chromium-based desktop runtime)
- Local database

## Project Structure

The `www` directory contains the main application source code.

## Security

This repository must not contain personal adolescent records,
real database credentials, private keys, or production data.

## Dependencies

Third-party PHP dependencies are not included in the source
repository. Dependency restoration instructions are pending
verification of the original Composer configuration.
